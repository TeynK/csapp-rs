# csapp-rs

CSAPP 6~12장 × Rust 실습 저장소. 날마다 `days/` 아래 패키지 하나.

| Day | 폴더 | 실행 | 상태 |
| --- | --- | --- | --- |
| D0 | days/d00-xxd-lite | `cargo run -p xxd-lite -- <파일>` | 완료 |
| D0-일 | days/d00-wc-lite | `cargo run -p wc-lite -- [-l] [-w] [-c] <파일>...` | 완료 |
| D1 | days/d01-addr-split | `cargo run -p addr-split -- <주소> -s <s> -E <E> -b <b> [-m <m>]` | 완료 |
